# Scan2World Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Docker-based web app: photos → COLMAP reconstruction → browser studio → game-map prep → validated exports.

**Architecture:** NestJS api + BullMQ worker orchestrate three internal FastAPI services (vision, recon, geometry) over a shared `/data` volume; Postgres is the source of truth; React/R3F frontend talks only to the api.

**Tech Stack:** Node 22, NestJS 11, Prisma 6, BullMQ 5, Postgres 16, Redis 7; Python 3.11 (3.10 in the COLMAP image if that is what it ships), FastAPI, OpenCV, Open3D, trimesh; Vite, React 18, TS, Tailwind, R3F/drei, TanStack Query, Zustand, RHF+Zod; Jest, pytest, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-26-scan2world-design.md`

## Global Constraints

- All routes under `/api/v1`; error shape `{ error: { code, message, requestId, details? } }`.
- DB/APIs store storage keys only; never return filesystem paths.
- Python services: no published ports; require header `X-Service-Token: $SERVICE_TOKEN`.
- Subprocesses: argument lists, never `shell=True`; every call has a timeout.
- Job states: queued, validating, running, processing, exporting, completed, failed, cancelling, cancelled.
- No invented progress percentages; no FBX; no navmesh claims.
- Uploads: JPEG/PNG/WebP by magic bytes; defaults MAX_IMAGES=200, MAX_FILE_MB=40.
- Recon concurrency 1.

## Review Focus

1. Upload with a spoofed extension (e.g. `.jpg` containing text) → rejected 415 with clear message. (Task 3)
2. COLMAP registers no model (unrelated photos) → job `failed` with `sparse_reconstruction_failed` + capture advice, not a hang. (Task 6)
3. User B requests user A's project/asset/download by id → 404. (Task 2, 3, 9)
4. Worker container restarts mid-job → job re-attached or failed `worker_lost`, never stuck `running`. (Task 7)
5. Studio opens an asset whose file is corrupt/missing → error panel, not infinite spinner. (Task 8)
